# 📜 Трекер видеолекций по истории

Минималистичный одностраничный трекер учебных видеолекций по истории (для подготовки к ЕГЭ и Олимпиадам). Написан на чистом HTML, CSS и JavaScript без использования сторонних фреймворков и библиотек.

🔗 **Демо / GitHub Pages:** [https://ennui-hist.github.io/history-tracker/](https://ennui-hist.github.io/history-tracker/)

---

## ✨ Возможности

- **Прогресс-бар:** динамический подсчёт общего процента и количества просмотренных лекций во всей базе.
- **Фильтрация и живой поиск:**
  - Моментальный поиск по названиям лекций и тексту конспектов;
  - Фильтры по лекторам: *Гончаров, Борисов, Данилевский, Станишевский*;
  - Фильтры по формату: *ЕГЭ, Олимпиады*;
  - Фильтры по статусу: *Все, Не просмотрено, Просмотрено*.
- **Таймкоды:** отдельное поле для фиксации времени остановки (с янтарной подсветкой начатых лекций).
- **Конспекты и заметки:** плавно раскрывающееся поле для заметок, дат и терминов с индикатором наличия текста.
- **Редактирование:** возможность быстро изменить название, ссылку, лектора или формат в карточке.
- **Безопасность данных:**
  - Автоматическое сохранение в `localStorage` браузера на лету;
  - Подтверждение при удалении лекций;
  - Экспорт и импорт базы в формате JSON (скачивание и загрузка бэкапа).
